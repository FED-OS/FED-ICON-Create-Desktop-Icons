🖥️ Platform Guidelines specs

Everything you need to ship icons that look perfect on every operating system — formats, sizes, shapes, and safe zones at a glance.

🍎

macOS

  • Format: .icns, .png
  • Sizes: 16–1024px (multi-size)
  • Shape: Squircle (superellipse)
  • Safe Zone: 10% padding margin
  • Resolution: 72dpi standard
  • Grid: 512×512 design canvas
💡 macOS auto-applies the squircle mask — design your icon on a square canvas and keep important content within the inner 80%.
🪟

Windows

  • Format: .ico, .png
  • Sizes: 16, 32, 48, 256px
  • Shape: Square (no forced rounding)
  • Safe Zone: Fill entire canvas
  • Resolution: 96dpi
  • Color: Supports alpha transparency
💡 Bundle all sizes into a single .ico file. Windows scales to the taskbar, Start menu, and Alt-Tab automatically.
🐧

Linux

  • Format: .svg (preferred), .png
  • Sizes: 16–512px (scalable)
  • Shape: Theme-dependent
  • Safe Zone: Variable per theme
  • Resolution: 96dpi
  • Theme: hicolor is the fallback
💡 Provide an SVG in scalable/apps/ plus PNG fallbacks. Follow the Freedesktop icon naming spec for cross-DE support.
📱

iOS

  • Format: .png (no transparency)
  • Sizes: 180×180 (iPhone), 1024 (App Store)
  • Shape: Squircle (iOS 7+)
  • Safe Zone: 20% margin
  • Resolution: @2x, @3x assets
  • Background: Solid, no alpha
💡 Apple applies the rounded mask & gloss automatically. Use a solid background fill — transparent areas render as black.
🤖

Android

  • Format: .png, .xml (adaptive)
  • Sizes: 48–512px, adaptive 108dp
  • Shape: Adaptive (circle, squircle, etc.)
  • Safe Zone: 20% (adaptive inner)
  • Resolution: mdpi→xxxhdpi
  • Play Store: 512×512 icon
💡 Adaptive icons split foreground & background layers. Keep your logo inside the central 66% safe zone to survive any mask shape.
🌐

Web / PWA

  • Format: .svg, .png, .webp
  • Sizes: 16 (favicon) – 512 (PWA)
  • Shape: Square or maskable
  • Safe Zone: 10% (maskable)
  • Resolution: 1x, 2x, 3x
  • Manifest: icons array
💡 Declare a 512×512 maskable icon in your manifest so Android home screens crop safely. Include an SVG favicon for crisp rendering.

🧩 Pro SVG Techniques

🎨 currentColor for theming

Use currentColor so icons inherit text color — perfect for dark/light themes without duplicate assets.

<svg fill="currentColor"> <path d="..." /> </svg>

📐 viewBox & consistent stroke

Lock the viewBox to 24×24 and keep stroke-width uniform (1.5–2px) across a set for visual harmony.

<svg viewBox="0 0 24 24" stroke="currentColor" stroke-width="2">

⚡ Optimize with SVGO

Strip metadata, round paths, and collapse groups. Run SVGOMG before shipping to cut file size by 30–60%.

# CLI npx svgo input.svg -o output.svg # or use svgomg.net

🎯 Design Principles best practices

🔍 Clarity

Your icon must be legible at 16×16. Every pixel counts.

⚖️ Consistency

Keep stroke weights, corners, and visual balance uniform.

🎨 Metaphor

Use familiar symbols — users shouldn't decode abstract shapes.

📐 Grid

Design on a pixel grid (e.g., 24×24) to avoid fuzzy edges.

🌈 Color

Limit palette. Use contrast for accessibility. Test on dark/light.

🧩 Scalability

Start with a vector (SVG) then export to all raster sizes.

♿ Accessibility & Optimization a11y

Icons that everyone can use — and that load fast. Essential best practices for inclusive, performant icon systems.

🔇 Decorative icons

Hide from screen readers with aria-hidden="true". If it's purely visual, don't announce it.

📢 Meaningful icons

Provide an aria-label or visible text label when the icon conveys action (e.g., a lone close button).

📏 Touch targets

Keep clickable icon hit areas at least 44×44px (WCAG 2.5.5). The visual can be smaller; the target shouldn't.

🌗 Contrast

Maintain a 3:1 ratio for graphical objects (WCAG 1.4.11). Test icons against both light and dark surfaces.

🌲 Tree-shaking

Import only the icons you use (react-icons, Lucide) so bundlers drop the rest. Don't ship 4,000 icons.

📦 Bundle size

Inline critical SVGs, lazy-load the rest. Optimize with SVGO and prefer <symbol> sprites for repeats.

⌨️ Focus states

Icon-only buttons need a visible focus ring. Never rely on color alone to show state.

🕊️ Reduced motion

Respect prefers-reduced-motion — disable spinning/pulsing icon animations for sensitive users.

📋 Quick Reference cheatsheet

📐 Standard Sizes
  • • 16×16 — favicon / status bar
  • • 24×24 — toolbar / navigation
  • • 32×32 — taskbar / system tray
  • • 48×48 — desktop shortcut
  • • 64×64 — thumbnail / preview
  • • 128×128 — file preview
  • • 256×256 — Windows app icon
  • • 512×512 — macOS / Android
  • • 1024×1024 — App Store / Play
🧩 File Formats
  • • .svg — vector (scalable, editable)
  • • .png — raster (transparent, lossless)
  • • .ico — Windows multi-size container
  • • .icns — macOS icon set
  • • .webp — modern web (small + alpha)
  • • .bmp — legacy raster
  • • .xpm — X Window System
  • • .gif — animated (rare for icons)
🎨 Color Psychology
  • 🔵 Blue — trust, calm, tech
  • 🟢 Green — growth, nature, go
  • 🔴 Red — urgency, passion, stop
  • 🟡 Yellow — optimism, warning, energy
  • 🟣 Purple — luxury, creativity, mystery
  • 🟠 Orange — enthusiasm, friendly
  • ⚫ Black — power, elegance, premium
  • ⚪ White — purity, simplicity, clean
📐 DPI Buckets (Android)
  • • mdpi — 1× (160dpi)
  • • hdpi — 1.5× (240dpi)
  • • xhdpi — 2× (320dpi)
  • • xxhdpi — 3× (480dpi)
  • • xxxhdpi — 4× (640dpi)
🍎 iOS Asset Scale
  • • @1x — base (legacy)
  • • @2x — Retina (iPhone SE+)
  • • @3x — Super Retina (Pro)
  • • App Store — 1024×1024
♿ A11y Quick Checks
  • • Decorative → aria-hidden
  • • Meaningful → aria-label
  • • Contrast ≥ 3:1 (graphics)
  • • Touch target ≥ 44×44px
  • • Respect reduced-motion
